# Quote Generator with History

A modern, responsive web application that fetches quotes from public APIs, provides daily quote inspiration, allows one-click copying to clipboard, and persists user favorites in a backend database table.

## Features

- **Public API Integration**: Fetches quotes dynamically with resilient curated fallback.
- **Daily Quote**: Get today's featured quote of the day.
- **Favorites Database Table**: Backend persistent storage saving user favorite quotes.
- **Favorites History UI**: Interactive drawer and list with live count, search filter, and delete options.
- **Copy to Clipboard**: Instant copy of formatted quote and author with toast confirmation.
- **Vercel Ready**: Preconfigured for seamless deployment.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
